AI Resume Analyzer | React, Node.js, MongoDB, RAG, LangChain, LLaMA 3.3, Vector DB
*Objective: Built an intelligent resume-screening platform leveraging a RAG architecture to semantically match candidate profiles against job requirements.*
• Engineered a **full-stack AI platform** using **Node.js** and **React**, integrating a **RAG pipeline** via **LangChain** to process **500+ resumes**, cutting screening time by **70%**.
• Implemented **500-char semantic chunking** and a **vector store** using **all-MiniLM-L6** embeddings, boosting context retrieval accuracy by **40%** via **cosine similarity**.
• Orchestrated an **agentic AI flow** with **LLaMA 3.3** and **prompt engineering**, utilizing **Zod schemas** to guarantee **100% JSON output integrity** for **5+ ATS data points**.
• Developed secure **REST APIs** with **JWT auth** and **MongoDB**, optimizing **PDF parsing** to process **5MB files under 2 seconds** and handle **100+ concurrent uploads**.
